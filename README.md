# Pain

*A final-year journalism feature by Ellis Ng*, rebuilt as a Jekyll site using a
port of the [Chalk](https://github.com/nielsenramon/chalk) theme (MIT, by
Nielsen Ramon).

## Fonts

- **Links:** Raleway (Google Fonts)
- **Headlines:** Essonnes Display (Adobe Fonts)
- **Body copy:** Kepler Std (Adobe Fonts)

Inter stands in for Essonnes and Kepler until you add an Adobe Fonts web project
ID as `typekit_id` in `_config.yml`.
